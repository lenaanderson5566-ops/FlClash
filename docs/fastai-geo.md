# FastAI 内置规则数据

安装包已通过 `assets/data/` 包含 `GEOIP.dat`、`GEOSITE.dat`、
`GEOIP.metadb` 和 `ASN.mmdb`。启动内核前会比较安装包与使用目录的
SHA-256；缺失、损坏或被在线更新过的文件会以安装包版本恢复，
匹配的文件不会重复写入。升级 App 后自动使用新包中的数据。

FastAI 的配置下载、最终配置合并和动态配置更新均关闭 Geo 自动更新。
资源管理页面已删除，手动更新请求也会被拒绝。

默认服务端模板没有远程规则集。配置中的 HTTP 规则提供者或规则提供者
URL 会被拒绝，不会下载，也不会静默丢弃规则。内联规则和随 App
发布的本地规则可以使用；增加本地规则文件时须同时加入安装包。

发布新版时统一维护以上四个数据文件，保留数据来源及许可证，并测试
其与当前 Mihomo 内核的兼容性。运行中的客户端不访问数据更新地址。
